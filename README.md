# Customer Segmentation Analysis

**Thiranex Internship – Task 2**

An interactive **Power BI dashboard** developed to analyze customer behavior, spending, engagement, preferences, customer segments, and churn risk using **Python, K-Means Clustering, and Power BI**.

### 📊 Dashboard

![Customer Segmentation Dashboard](https://github.com/mandaneha/Customer-Segmentation-Analysis/blob/main/customer_segmentation_dashboard.png)

### 📈 Key Insights

* **Total Customers:** 2,000
* **Total Spend:** approximately **147.97M**
* **Overall Churn Rate:** approximately **12.1%**
* **High-Value Customers:** 272 customers
* **Valuable Active Customers:** 514 customers
* **Regular Customers:** 671 customers
* **At-Risk Customers:** 543 customers
* **High-Value Customers** had the highest average order value at approximately **4,317**.
* **At-Risk Customers** had the highest churn rate at approximately **25%**.
* **High-Value Customers** had the lowest churn rate at approximately **1%**.

### 🔎 Dashboard Features

* Customer segment distribution
* Average order value analysis
* Customer engagement analysis
* Customer preference analysis
* Customer churn risk analysis
* Total spending by customer segment
* Customer Segment, Region, Gender and Preferred Category filters
* Interactive Power BI visualizations

### 🤖 Customer Segmentation

Customers were segmented using the **K-Means Clustering** algorithm based on:

* Annual Income
* Purchase Frequency
* Average Order Value
* Total Spend
* Recency

The analysis identified **4 customer segments**:

* **High-Value Customers**
* **Valuable Active Customers**
* **Regular Customers**
* **At-Risk Customers**
